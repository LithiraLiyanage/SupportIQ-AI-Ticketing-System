## 🌟 Overview

**SupportIQ** is a modern **AI-powered MERN customer support ticketing system** built for real-world SaaS support workflows.

Customers can create support tickets, AI automatically detects **priority, category, sentiment, summary, and tags**, agents resolve tickets using **real-time comments**, and admins monitor **SLA breaches, analytics, audit logs, agents, notifications, and ticket performance**.

## 🧠 AI Ticket Triage

SupportIQ includes a **rule-based AI triage engine** that works without paid APIs.

The AI analyzes ticket title and description to detect:

| AI Output    | Example                                    |
| ------------ | ------------------------------------------ |
| 🗂️ Category | Billing, Account Access, Bug Report        |
| 🚦 Priority  | Low, Medium, High, Critical                |
| 😊 Sentiment | Positive, Neutral, Negative, Angry, Urgent |
| 📝 Summary   | Short support-focused ticket summary       |
| 🏷️ Tags     | login, billing, bug, refund, api           |
| 🎯 Tone      | Professional, empathetic, urgent           |

### 🚨 Critical Priority Keywords

```text
account hacked
security issue
data loss
production outage
cannot access account
payment failed repeatedly
system down
urgent refund escalation
```

## 🧑‍💻 Run Locally

### 1️⃣ Start MongoDB

```bash
docker compose up -d mongo
```

### 2️⃣ Start AI Service Optional

```bash
cd ai-service
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

### 3️⃣ Start Backend

```bash
cd backend
npm install
copy .env.example .env
npm run dev
```

Backend URL:

```text
http://localhost:5000
```

### 4️⃣ Start Frontend

```bash
cd frontend
npm install
copy .env.example .env
npm run dev
```

Frontend URL:

```text
http://localhost:5173
```
